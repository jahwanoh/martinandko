# Martin&Ko Hair Salon

A static salon website for Martin&Ko in Angel, Islington. GitHub Pages serves the root of the `main` branch. Booking links go to Fresha.

## Preview locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000`.

Salon details, service prices and documentary photos come from the [supplied Fresha listing](https://www.fresha.com/en-GB/a/martin-ko-hair-salon-london-9-camden-passage-mmh2p1ih). The hero and service photos are AI-generated architectural illustrations. The self-hosted fonts use the SIL Open Font License, included in `assets/fonts`.
